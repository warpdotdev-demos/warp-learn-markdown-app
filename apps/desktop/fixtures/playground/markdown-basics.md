# Markdown Basics

Marky renders standard Markdown as you type. Edits save straight to this file.

## Text

You can write **bold**, *italic*, ~~strikethrough~~, and `inline code`.

## Lists

- Bulleted item
- Another item

1. Numbered item
2. Another item

- [x] A finished task
- [ ] An open task

## Links

Link to another note with double brackets, like [[welcome]], or to a website with [a normal link](https://www.warp.dev).

## Code

```ts
function greet(name: string) {
	return `Hello, ${name}!`;
}
```

## Tables

| Shortcut | Action |
| --- | --- |
| `Cmd+N` | New note |
| `Cmd+K` | Search |

> Tip: open the note menu and choose Edit Source to see the raw Markdown.
