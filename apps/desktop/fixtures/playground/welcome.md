# Welcome to Marky

Marky is a small, local-first Markdown editor. Every note is a plain `.md` file in a folder on your computer.

## Getting around

- The sidebar lists every file in this folder. Click a note to open it.
- Press `Cmd+N` to create a new note.
- Press `Cmd+K` to search notes and commands.
- Type `/` in a note to insert headings, lists, tables, and more.
